# AE 素材医生 · AE Media Doctor

检查 After Effects 工程里**丢失的素材链接**，并把它们重新接回本地文件。

不改二进制、不猜路径：调用 AE 自己的 ExtendScript 接口（`footageItem.replace`）逐条重连，然后保存工程。工程默认**先复制一份再改**，原件不动。

```
┌─ 工程文件 ────────────────────────────────┐
│  选 .aep / .aepx                          │
│  After Effects 版本（自动列出本机已装版本） │
├─ 素材搜索目录 ────────────────────────────┤
│  Footages\、素材\ …  按顺序递归找同名文件   │
│  ☑ 缺失后全盘补搜（内置 Everything）        │
├─ 选项 ────────────────────────────────────┤
│  ☐ 只体检   ☑ 先复制一份再改                │
│  ☐ 收编到工程 Footages   ☑ 完成后关闭本次打开的 AE │
└───────────────────────────────────────────┘
```

## 它解决什么问题

拿到别人的 `.aep`，打开满屏「媒体离线」——因为原工程里写的是对方的绝对路径（比如 `E:\素材\02\…\1 (1).mp4`），而你手上是同名素材放在另一个目录。

手工重链几十条素材很痛苦，这个工具把它变成两步：**选工程 → 选素材目录 → 开始检查**。

## 用法

1. 解压后双击 `启动.cmd`（或 `python app.py`）。
2. 选工程、选素材目录（选工程后会自动推断同级的 `Footages`、`素材` 等）。
3. 点「开始检查」，等 AE 跑完；结果在 KPI 三格与日志里。
4. 缺失的看「缺失清单」，或打开「缺失后全盘补搜」再跑一轮。

命令行也能用：

```bat
python app.py --cli "D:\工程\xxx.aep" --dry
python app.py --cli "D:\工程\xxx.aep" --roots "D:\素材;E:\备份" --no-save
```

## 匹配规则（重要）

- 先按**完整文件名**匹配；找不到再退到「短基名 + 扩展名」：`1 (1).mp4` 能匹配到
  `1 (1).119.880fps.QE.HW…_fa3cd1.mp4`（补帧软件导出时常在后面加一长串）。
- 多个候选时取第一个，少的那些会被记进日志（`ambiguous`）。
- 只按文件名匹配、**不比对内容**：同名但不同内容的文件会被接上。跑完请扫一眼日志。
- 全盘补搜用的是内置的 Everything（ES 命令行），每名最多取 3 个命中目录。

## 运行条件

- Windows，Python 3.8+（只用标准库 tkinter，不需要 pip 装任何东西）。
- 已安装 After Effects 2021–2026（工具会列出本机已装的版本）。
- 「全盘补搜」需要 Everything（不随仓库分发，运行 `python tools/fetch_engine.py` 自动下载到 `engine/Everything/`）。

## 已知限制

- 补搜可能把别人的同名文件接进工程；接错就手动删搜索目录重跑。
- 首次补搜要申请一次管理员权限（Everything 建索引需要）。
- 只处理 `FileSource` 素材；合成、预合成里的引用不在范围。
