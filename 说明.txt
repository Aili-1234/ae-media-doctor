AE 素材医生 v1.7
====================

这版修了两件事（v1.7）
------------
· 关窗口时不再闪一个蓝色的 PowerShell 窗口：所有后台命令都改成静默运行，看不见黑框/蓝框。
· 窗口左上角和任务栏恢复成医生图标（紫底白加号，doctor.ico 随包附带）。
   注意：托盘里 Everything 的橙色放大镜只在「全盘补搜」真正跑起来时出现，
   程序关闭时会把它一起收走，这是有意的，不是丢图标。

它是干什么的
------------
别人发来的 AE 工程，打开后素材全丢（一堆「1 (1).mp4」离线）。
这个工具去你本机的素材文件夹里按名字把它们找回来，用 AE 官方接口重新链接并保存。
修完的工程，效果和你自己在 AE 里手动「替换素材」完全一样。

运行条件
--------
· Windows 10 / 11
· 本机装有 Python 3（打包时用的是 C:\Python315\python.exe，自带 tkinter 即可，无需装第三方库）
· 本机装有 After Effects 2021 – 2026 任意版本（工具有「开始检查」时才需要 AE）

怎么用
------
1  双击 启动.cmd（或桌面的「AE 素材医生」快捷方式）
2  点「选择…」选中素材丢失的 .aep
3  「素材搜索目录」里会自动加进工程同级目录与 Footages；素材在别处就点「添加…」
4  第一次建议勾「只体检（不改工程、不保存）」，先看缺多少
5  正式修复保持「先复制一份再改」，生成的 工程名_fixed.aep 才是结果，原件不动
6  点「开始检查」，等状态栏提示完成

点右上角「使用说明」，同样的内容在软件里也能看。

结果在哪
--------
工程同目录会生成三份：
  _relink_log.txt      逐条记录
  _relink_missing.txt  仍缺的素材（文件名 + 工程里的原路径）
  _relink_report.json  统计，界面靠它显示数字

找不到的素材：系统索引补搜（自带 Everything）
----------------------------------------------
本程序自带 Everything 便携版，就在 engine\Everything\ 里，不需要你另外安装。

一轮跑完还有 MISSING 的，程序会拿这些文件名去 Everything 里再找一遍：
  · Everything 没在跑 → 自动拉起（最小化，不占你屏幕）
  · 首次索引需要管理员权限 → 会弹一次 UAC，点「是」即可，之后一直可用
  · 命中后自动把命中文件所在目录加进「素材搜索目录」，再点一次「开始检查」就能接上
Everything 起不来时，会自动退回 Windows 搜索索引（只搜已建索引的磁盘，默认只有 C 盘）。

· 只按文件名匹配、不比对内容：同名不同文件（比如 02.mp4）可能认错，跑完先看日志里的 INDEX + 目录行
· 每个缺失名最多取前 3 条命中，去重后加目录；不会自动重跑，也不会删你手动加过的目录
Everything 随开关同步：开关关掉时程序会把它关掉（只关自己那份，你自己装的 Everything 不动），
关窗口时也会一起收走；开关打开时它只在你真的要补搜时才被拉起。

开关在「素材搜索目录」标题右边：「缺失后全盘补搜」，默认开。
不想让它每次跑完都查一遍，可以关掉。

老的说明（仅 Windows 索引的情况）
--------------------------
一轮跑完还有 MISSING 的，程序会自动拿这些文件名去系统索引里再找一遍：
  · 装了 Everything → 走 es.exe，全盘秒查（推荐，D/E 盘也能搜）
  · 没装           → 走 Windows 搜索索引（只搜已建索引的磁盘，默认只有 C 盘）
命中后它会把命中文件所在目录自动加进「素材搜索目录」，再点一次「开始检查」即可接上。
两边都搜不到，才是本机真没有：拿着 _relink_missing.txt 回去要文件。

这个开关在「素材搜索目录」标题右边：「缺失后全盘补搜」，默认开。
不想让它每次跑完都查一遍，可以关掉。

会弹对话框是正常的
------------------
工具通过 AE 的命令行脚本接口工作。AE 启动时若弹：
  「崩溃修复选项」→ 点「继续」
  「解析字体」   → 点「确定」
不点掉，脚本不会继续，界面会停在运行中。

注意
----
· 跑之前最好关掉 AE 里正在编辑的其他工程，避免互相干扰。
· 「收编到工程 Footages」会把素材复制进工程目录，方便打包发人，代价是占空间。
· 「只体检」不会保存，随便点。
· 完成后关闭 AE 默认勾选，免得 AE 一直占内存。

命令行（可选）
--------------
"C:\Python315\python.exe" app.py --cli "D:\工程\xxx.aep" --dry
  --dry                  只体检
  --no-save              不保存工程
  --roots "D:\a;E:\b"    指定素材搜索目录（分号分隔）
退出码：0 成功，1 超时（多半是 AE 弹窗没点），2 没找到 AE

目录内容
--------
  app.py               主程序（纯 Python 标准库）
  启动.cmd             双击启动
  说明.txt             本文件
  截图-主界面.png
  截图-使用说明.png
【设置会被记住】
下面这些选项改完就生效，下次打开还是你上次的状态：
  只体检 / 先复制一份再改 / 收编到工程 Footages / 完成后关闭本次打开的 AE / 缺失后全盘补搜、
  以及当前选的 After Effects 版本、上次打开的工程、素材搜索目录列表。
存在 %APPDATA%\AE素材医生\settings.json，删掉这个文件就回到出厂状态。

【关于「完成后关闭本次打开的 AE」】
工具要跑脚本，必须自己拉起一次 AfterFX.exe；跑完把这次拉起的那个 AE 收走，
免得它一直占着工程文件、下次跑不起来。只按进程号关本次启动的那一个，
你自己开的 AE 不会被关；有缺失要补搜时也不关（还要再跑一轮）。
